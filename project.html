Online Booking System

For our course project, I created an online hotel booking system using Dart and Flutter. The application allows users to browse available hotels and book a hotel room. I integrated Firebase as the database to store user information, hotel details, and booking records. FireAuth was implemented for secure authentication, ensuring that only registered users can access their accounts. The app features a user-friendly interface with smooth navigation. Users can sign up, log in, and manage their bookings efficiently. Real-time updates ensure that hotel availability is always accurate. I also incorporated error handling to improve the app’s reliability. The project helped me enhance my skills in Flutter, Firebase, and authentication systems.
